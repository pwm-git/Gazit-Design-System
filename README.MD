# Design System Gazit Brasil

Design system unificado da identidade visual da Gazit Brasil, usado como base
para os relatórios mensais de performance de redes sociais (Instagram e TikTok)
de todos os shoppings da carteira, exceto Prado Boulevard.

## Shoppings cobertos

- Gazit Brasil (marca guarda-chuva)
- Top Center Shopping
- Mais Shopping
- Shopping Light
- Morumbi Town Shopping
- Internacional Shopping

## Cores institucionais

| Nome | CMYK | RGB | Hex aproximado |
|---|---|---|---|
| Azul-marinho escuro | 100/80/0/70 | 22, 29, 66 | #161d42 |
| Dourado | 43/43/86/16 | 139, 124, 63 | #8b7c3f |
| Vinho | 0/100/65/30 | 150, 17, 50 | #961132 |
| Cinza neutro | - | - | #656565 |

Uso institucional padrão nos relatórios:
- Azul-marinho escuro: cor base
- Dourado: destaques e números
- Vinho: alertas e pontos de atenção
- Cinza: textos secundários

## Cores extraídas do site institucional (gazitbrasil.com)

- Texto principal: #343744
- Texto secundário: #5f5f5f
- Fundo de rodapé: #fcfcfc
- Bordas / botões outline: #6a6c76

## Tipografia

Fonte única: Barlow (títulos, menus, textos, botões)

Escala tipográfica:
- Título de capa: 60px
- Título de seção: 36px
- Subtítulo: 24px
- Corpo de texto: 16px
- Legenda: 12px
- Número de destaque / KPI: 80px

## Espaçamento (escala base 8)

- Extra pequeno: 8px
- Pequeno: 16px
- Médio: 24px
- Grande: 40px
- Extra grande: 64px (separação entre seções)

## Raio de borda

- 4px: botões e tags pequenos
- 8px: cards e blocos maiores

## Uso

Este design system serve de esqueleto visual para os relatórios mensais
automatizados de performance de redes sociais de cada shopping da carteira
Gazit. Cada shopping pode ter sua própria paleta de acentos extraída do
próprio site, mas segue sempre a tipografia, escala e tokens de espaçamento
definidos aqui.
